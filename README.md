# Bucin Quest — Sakura Miku Edition

Mini game web statis bertema sakura. Tangkap 15 hati dalam 30 detik untuk membuka hadiah Sakura Miku dari Aishiteru Game.

## Struktur
- `index.html` — halaman utama
- `assets/css/style.css` — seluruh styling dan animasi
- `assets/js/game.js` — logika permainan

## Menjalankan
Buka `index.html` di browser, atau gunakan Live Server pada VS Code.

## Hosting
Proyek ini tidak memerlukan backend/database. Bisa di-host melalui GitHub Pages atau Cloudflare Pages.

## Gambar
Gambar hadiah menggunakan URL eksternal yang diberikan. Jika URL tidak dapat dimuat, simpan gambar yang boleh digunakan ke folder lokal dan ubah nilai `src` di `index.html`.
